# BookClubApp

## Интерфейс авторизации

`AuthWindow` содержит `MainFrame`. Экраны находятся в `BookClubApp/Pages`:

- `LoginPage` — вход, запоминание выбора и вход как гость.
- `PasswordRecoveryPage` — ввод номера телефона.
- `ConfirmationCodePage` — шесть ячеек кода и таймер повторного запроса.
- `NewPasswordPage` — новый пароль и повторный ввод.
- `PasswordSuccessPage` — подтверждение смены пароля.
- `PhoneNotFoundPage` — номер не найден.
- `InvalidCodePage` — неверный код.
- `TooManyAttemptsPage` — превышено число попыток.

Кнопка «Забыли пароль?» открывает последовательность восстановления. «Войти» и
«Войти как гость» открывают существующую `ProductsTablePage`.

Это только фронтенд: кнопки переключают страницы, SMS не отправляются, пароль
не сохраняется, учётные данные не проверяются. Чекбокс не сохраняет выбор после
закрытия страницы. Экран успешной смены пароля пока является частью демонстрации.
Экраны ошибок подготовлены отдельно для подключения к результатам будущей проверки.
Для их просмотра можно временно передать соответствующую страницу в
`MainFrame.Navigate(new PhoneNotFoundPage())` в конструкторе `AuthWindow`.

Цвета и кисти находятся в `Styles/ColorStyles.xaml`, стили элементов — в
`Styles/AuthStyles.xaml`, векторные иллюстрации — в `Styles/AuthIllustrations.xaml`.
Словари подключены в `App.xaml` в порядке зависимостей. Иллюстрации перерисованы
средствами WPF по приложенному макету; исходный логотип проекта сохранён.
